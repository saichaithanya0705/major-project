# Artifact Lifecycle Cleanup Plan

## Goal

Implement a permanent cleanup pattern for files generated by sessions and interactions without touching user-owned saved work.

## Cleanup Rules

- Keep chat session JSON until the existing archive/delete lifecycle removes it.
- Keep active CLI background logs while the managed process is alive; prune stale inactive logs from temp.
- Delete transient browser profiles, browser-use run folders, debug screenshots, temp TTS audio, runtime state, and opened vision-artifact PNGs after short TTLs.
- Prune generated application logs by age and rotate the assistant activity JSONL when it grows beyond the configured size.
- Restrict deletion to known temp/log roots and known filename prefixes.

## Implementation Steps

1. Add failing tests for Python cleanup boundaries and TTS temp cleanup.
2. Add failing tests for Electron vision artifact cleanup.
3. Implement `core.artifact_lifecycle` with safe path checks, TTL rules, and a structured cleanup report.
4. Wire cleanup into app startup/shutdown-adjacent paths and browser/CLI lifecycle helpers.
5. Move ElevenLabs TTS output to temp storage and delete it after successful playback.
6. Extract Electron vision image cleanup into a pure helper and run it on startup, open, and quit.
7. Run targeted Python and Node-backed tests.
